# Découverte de WordPress

Bienvenue dans ce support de cours consacré à la découverte de WordPress, dans le cadre du module de communication digitale du BUT Information-Communication.

## Objectifs du cours

À l'issue de ce cours, vous serez capable de :

- Comprendre le fonctionnement d'un CMS (Content Management System)
- Installer et configurer WordPress
- Personnaliser un site avec un thème
- Étendre les fonctionnalités via des plugins
- Réaliser un premier site WordPress complet

## Organisation

Le cours est découpé en cinq chapitres, accessibles dans le menu de navigation à gauche. Chaque chapitre se termine par des points clés à retenir.

!!! tip "Conseil"
    Travaillez avec un environnement de test local (XAMPP, MAMP ou Local) pour expérimenter librement sans risque.

## Prérequis

Aucune connaissance préalable de WordPress n'est nécessaire. Des bases en HTML/CSS sont un plus mais ne sont pas indispensables pour ce premier contact avec le CMS.
