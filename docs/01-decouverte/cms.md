# Qu'est-ce qu'un CMS ?

Un **CMS** (Content Management System, ou système de gestion de contenu) est une application qui permet de créer, modifier et publier du contenu sur un site web sans avoir besoin de connaissances techniques approfondies en développement.

## Le principe

Avant l'apparition des CMS, créer ou modifier une page web nécessitait d'écrire du code HTML directement. Un CMS sépare deux choses :

- le **contenu** (textes, images, articles, pages)
- la **présentation** (mise en page, design, structure visuelle)

Cette séparation permet à un rédacteur de publier un article sans toucher au code, et à un développeur de modifier le design sans toucher au contenu.

## Les composants principaux

| Composant | Rôle |
|---|---|
| Back-office (administration) | Interface pour gérer le contenu |
| Front-office | Le site tel que vu par les visiteurs |
| Base de données | Stockage du contenu |
| Thème | Habillage visuel du site |
| Extensions / plugins | Ajout de fonctionnalités |

!!! note "À retenir"
    Un CMS n'est pas qu'un outil technique : c'est avant tout un outil pensé pour rendre la publication de contenu accessible à des profils non-développeurs.

## Exemples de CMS courants

- WordPress (le plus répandu, environ 40% des sites web dans le monde)
- Drupal
- Joomla
- Des CMS dédiés au e-commerce : Prestashop, Shopify, Magento
